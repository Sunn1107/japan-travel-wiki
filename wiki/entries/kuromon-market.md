# 黑門市場 (Kuromon Market)

黑門市場是一條長約 580 公尺的拱廊式傳統市場，兩側聚集海鮮、蔬果、肉鋪、和菓子與西洋糕點等各式店鋪，有「大阪人的廚房」之稱，且雨天也能輕鬆逛街。

## 1. 基本情報表

| 項目 | 詳細資訊 |
| :--- | :--- |
| **所屬城市與商圈** | 大阪 Osaka（日本橋・難波周邊） |
| **分類定位** | 🍜 美食 / 🎁 傳統糕點伴手禮 |
| **建議停留時間** | 1 ～ 2 小時（建議上午至中午前往） |
| **適合對象** | 海鮮與市場小吃愛好者、自由行旅客 |

## 2. 特色與推薦重點
- **市場現吃美食**：現切生魚片、現烤大干貝、海鮮串燒、和牛串與現榨新鮮果汁。
- **傳統伴手禮採買**：拱廊內設有多間和菓子老店與西洋糕點鋪，適合挑選日系點心禮盒。

## 3. 排隊與順遊動線攻略
- **最佳時段**：建議安排在上午 10:00 至中午 12:30 之間前往，店鋪營業最齊全；逛完後可步行前往 [道頓堀＋心齋橋](dotonbori-shinsaibashi.md) 繼續午後購物行程。
