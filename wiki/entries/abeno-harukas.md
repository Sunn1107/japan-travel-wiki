# 阿倍野 HARUKAS 展望台

位於大阪天王寺地區的高樓展望景點（HARUKAS 300），擁有 360 度大片落地玻璃，能夠無死角俯瞰大阪市區輪廓與關西平原夜景。

## 1. 基本情報表

| 項目 | 詳細資訊 |
| :--- | :--- |
| **所屬城市與商圈** | 大阪 Osaka（阿倍野・天王寺區） |
| **分類定位** | 🏯 景點（高空觀景台與夜景） |
| **建議停留時間** | 1 ～ 2 小時 |
| **適合對象** | 喜歡城市景觀、黃昏夕陽與高空夜景的旅客 |

## 2. 特色與推薦重點
- **最佳賞景時段**：推薦安排在「下午接近傍晚」時段登樓，一次收集白天城市輪廓、黃昏夕陽與入夜後萬家燈火三種景色。

## 3. 排隊與順遊動線攻略
- **天王寺半日圈**：下午可先參拜鄰近的歷史古剎「四天王寺」，傍晚前往阿倍野 HARUKAS 賞夜景，晚餐則可步行或搭車至附近的 [通天閣與新世界商圈](tsutenkaku-shinsekai.md) 品嚐串炸。
