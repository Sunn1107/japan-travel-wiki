# SHIBUYA SKY 澀谷展望台

位於澀谷車站正上方 Shibuya Scramble Square 頂樓的完全開放式露天展望台，無屋頂遮蔽且採用低矮透明玻璃設計，能 360 度俯瞰世界著名的澀谷十字路口與東京天際線。

## 1. 基本情報表

| 項目 | 詳細資訊 |
| :--- | :--- |
| **所屬城市與商圈** | 東京 Tokyo（澀谷區・澀谷站直結） |
| **分類定位** | 🏯 景點（露天高空展望台） |
| **營業時間** | 10:00 – 22:30（最終入場 21:20） |
| **地址** | 東京都渋谷区渋谷 2-24-12 |

## 2. 特色與推薦重點
- **360 度無死角露天視野**：俯瞰繁忙的澀谷十字路口人潮，天氣晴朗時還可遠眺富士山與東京鐵塔。
- **安全隨身物品規定**：露天屋頂風大，帽子、腳架與未固定之隨身包包需寄放於入口處免費置物櫃方可登頂。

## 3. 排隊與順遊動線攻略
- **日落黃金時段搶票**：下午 16:00–18:00 的日落場次最搶手，建議開放預約時即線上訂票；白天可先走訪 [明治神宮](meiji-jingu.md) 與原宿商圈。
