# teamLab Planets TOKYO

位於東京豐洲的超人氣沉浸式數位藝術美術館，透過光影、鏡面、花海與真實水面互動裝置，帶來赤腳走入藝術作品中的夢幻體驗。

## 1. 基本情報表

| 項目 | 詳細資訊 |
| :--- | :--- |
| **所屬城市與商圈** | 東京 Tokyo（江東區・豐洲） |
| **分類定位** | 🏯 景點（沉浸式數位藝術展覽） |
| **營業時間** | 09:00 – 21:00（採預約場次制） |
| **地址** | 東京都江東区豊洲 6-1-16 |

## 2. 特色與推薦重點
- **赤腳涉水體驗**：參觀需脫鞋赤腳走過水面展區與漂浮花朵空間，建議穿著方便捲起褲管的服裝（避免過短裙裝因地面鏡面反射曝光）。
- **絕美光影打卡**：每個展間皆為高度互動式光影空間，適合喜愛攝影與現代藝術的旅客。

## 3. 排隊與順遊動線攻略
- **務必提早購票**：展覽採預約制且熱門時段名額有限，建議出發前 **提早 1 個月** 線上預訂門票。
- **豐洲一日順遊**：早晨可先至鄰近的 [壽司大 (豐洲市場)](sushi-dai-toyosu.md) 品嚐握壽司，上午或下午參觀 teamLab，傍晚搭乘百合海鷗號前往 [台場海濱公園與彩虹大橋](odaiba-rainbow-bridge.md)。
