# 鮨 YAMAKEN (銀座黑鮪魚壽司吃到飽)

位於銀座核心地段的高人氣壽司餐廳，提供全日本罕見的「90 分鐘本鮪（黑鮪魚）握壽司吃到飽」，讓饕客一次盡情品嚐黑鮪魚各個頂級部位。

## 1. 基本情報表

| 項目 | 詳細資訊 |
| :--- | :--- |
| **所屬城市與商圈** | 東京 Tokyo（中央區・銀座） |
| **分類定位** | 🍜 美食（高級壽司放題・預約制） |
| **營業時間與預算** | 11:30–14:00、17:00–22:00｜午餐 ¥8,800 起、晚餐 ¥13,000 起 |
| **地址** | 東京都中央区銀座 5-13-19 DUPLEX銀座TOWER 9F |

## 2. 特色與推薦重點
- **黑鮪魚全部位無限享用**：90 分鐘內無限供應 **本鮪大腹（大トロ）**、**中腹（中トロ）** 與 **赤身**，另含海膽、鮭魚卵、甜蝦等高級海鮮握壽司。

## 3. 排隊與順遊動線攻略
- **務必事前預約**：店內座位數有限且採預約制，建議至少提早 **1 ～ 2 週** 線上訂位；餐後可直接在 [銀座精品街](ginza-shopping.md) 逛街消化。
