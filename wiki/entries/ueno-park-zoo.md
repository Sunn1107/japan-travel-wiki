# 上野恩賜公園與上野動物園

上野恩賜公園腹地遼闊，集結上野動物園、國立博物館與美術館，春天更是東京數一數二的賞櫻名所，非常適合親子家庭與文化愛好者安排半日遊。

## 1. 基本情報表

| 項目 | 詳細資訊 |
| :--- | :--- |
| **所屬城市與商圈** | 東京 Tokyo（台東區・上野） |
| **分類定位** | 🏯 景點（親子動物園與賞櫻公園） |
| **開園時間** | 動物園 09:30 – 17:00（最終入園 16:00，週一休園） |
| **地址** | 東京都台東区上野公園 9-83 |

## 2. 特色與推薦重點
- **親子人氣動物園**：園內可觀賞大貓熊與多種珍稀動物，假日下午看貓熊常需排隊，建議一開園即入園。
- **四季風景與博物館群**：春季櫻花大道浪漫壯觀，秋季銀杏金黃，周邊步行即達阿美橫丁商店街。

## 3. 排隊與順遊動線攻略
- **上野一日散步**：上午遊覽上野公園與動物園，中午步行至鄰近百年老店 [伊豆榮 (上野鰻魚飯)](izuei-ueno-unagi.md) 用餐，下午逛阿美橫丁採買藥妝零食。
