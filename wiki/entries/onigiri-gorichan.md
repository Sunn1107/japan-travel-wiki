# おにぎりごりちゃん (Onigiri Gorichan)

位於大阪北區中崎西的超人氣現捏日式手作飯糰專門店，以蓬鬆溫熱的米飯、豐富內餡以及「吃到一半可免費加入高湯變成茶泡飯」的二吃體驗聞名。

## 1. 基本情報表

| 項目 | 詳細資訊 |
| :--- | :--- |
| **所屬城市與商圈** | 大阪 Osaka（梅田 / 中崎町商圈） |
| **分類定位** | 🍜 美食（現捏手作飯糰專門店） |
| **交通與步行時間** | 阪急「大阪梅田站」或大阪地鐵谷町線「中崎町站」步行可達 |
| **營業時間與公休** | `[待實地確認]`（午餐尖峰 11:30–13:30 排隊約 30～60 分鐘） |

## 2. 特色與推薦重點
根據原始探店筆記（[大阪梅田排隊飯糰觀察](../sources/src-osaka-food.md)），店內提供超過 30 種內餡組合，必點推薦如下：
- **蛋黃醬油漬（卵黄醤油漬け）＋ 肉鬆（肉そぼろ）**：鎮店招牌雙拼組合，濃郁蛋黃與鹹香肉鬆極度下飯。
- **明太子奶油起司（明太クリームチーズ）**：鹹香明太子與滑順起司的經典搭配。
- **鮭魚卵（すじこ）**：海味鮮明，適合搭配後續的高湯茶泡飯吃法。

## 3. 排隊與順遊動線攻略
- **避開尖峰時段**：建議提早於開門前抵達，或安排在下午 14:00 後離峰時段造訪。
- **周邊順遊**：用餐後可散步逛中崎町古著巷弄，再步行返回梅田百貨商圈購物。
