# 明治神宮 (Meiji Jingu)

座落於代代木公園旁的東京最大神社，穿過宏偉的木造大鳥居、沿著碎石參道漫步於濃密森林綠蔭中，讓人瞬間遠離原宿與澀谷的都市喧囂。

| 項目 | 詳細資訊 |
| :--- | :--- |

| **分類定位** | 🏯 景點（森林神社與文化遺產） |
| **開放時間** | 日出至日落（依季節月份微調） |
| **地址** | 東京都渋谷区代々木神園町 1-1 |

## 2. 特色與推薦重點
- **神前婚禮與新年初詣**：神宮供奉明治天皇與昭憲皇太后，假日常可見穿著白無垢與紋付袴的日本傳統婚禮隊伍，亦是東京新年參拜人潮最多的神社。

## 3. 排隊與順遊動線攻略
- **原宿澀谷一日線**：上午安排參拜明治神宮享受森林芬多精，中午步行至原宿竹下通與表參道逛街用餐，傍晚前往 [SHIBUYA SKY 澀谷展望台](shibuya-sky.md) 欣賞夕陽夜景。
