# 淺草寺與雷門 (Senso-ji & Kaminarimon)

淺草寺是東京最古老的寺廟與最具代表性的歷史文化地標，巨大的紅色雷門燈籠與熱鬧的仲見世通商店街，完整保留了濃厚的江戶下町風情。

## 1. 基本情報表

| 項目 | 詳細資訊 |
| :--- | :--- |
| **所屬城市與商圈** | 東京 Tokyo（台東區・淺草） |
| **分類定位** | 🏯 景點 / 🎁 傳統和菓子伴手禮 |
| **開放時間** | 寺廟本堂 06:00 – 17:00（仲見世通依各店鋪而異） |
| **地址** | 東京都台東区浅草 2-3-1 |

## 2. 特色與推薦重點
- **雷門與仲見世通**：穿過雷門後沿著仲見世通散步，兩旁販售人形燒、仙貝等傳統小吃與各式日式和菓子紀念品。
- **和服體驗**：周邊和服租借店林立，非常適合換上和服在古色古香的街道拍照留念。

## 3. 排隊與順遊動線攻略
- **建議動線**：上午前往淺草寺參拜與逛仲見世通，午後步行跨越隅田川即可順遊 [東京晴空塔 (Tokyo Skytree)](tokyo-skytree.md)，傍晚再前往 [台場海濱公園與彩虹大橋](odaiba-rainbow-bridge.md) 賞夜景。
