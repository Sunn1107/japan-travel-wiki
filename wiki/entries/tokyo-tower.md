# 東京鐵塔 (Tokyo Tower)

紅白相間的經典東京精神地標，夜晚點亮溫暖的橘黃色燈光後格外浪漫，是情侶約會與夜景攝影的人氣首選。

## 1. 基本情報表

| 項目 | 詳細資訊 |
| :--- | :--- |
| **所屬城市與商圈** | 東京 Tokyo（港區・芝公園） |
| **分類定位** | 🏯 景點（經典地標與夜景） |
| **營業時間** | 09:00 – 23:00 |
| **地址** | 東京都港区芝公園 4-2-8 |

## 2. 特色與推薦重點
- **雙展望台視野**：可登上 150 公尺的主展望台或 250 公尺的特別展望台欣賞東京市區全景。
- **芝公園野餐賞櫻**：鐵塔腳下的芝公園綠意盎然，春天櫻花盛開時能拍出「櫻花＋東京鐵塔」的經典構圖。

## 3. 排隊與順遊動線攻略
- **夜景雙塔角度**：若想同時將東京鐵塔本身拍進畫面中，推薦傍晚前往鄰近的 [六本木之丘展望台 (東京 City View)](roppongi-city-view.md)。
