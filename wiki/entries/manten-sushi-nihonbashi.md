# Manten鮨 日本橋 (頂級 Omakase)

東京高評價無菜單壽司餐廳代表，提供由主廚依當日最新鮮時令漁獲設計的精緻 Omakase（主廚發辦）套餐，在板前座位近距離欣賞職人捏製工藝。

## 1. 基本情報表

| 項目 | 詳細資訊 |
| :--- | :--- |
| **所屬城市與商圈** | 東京 Tokyo（中央區・日本橋室町） |
| **分類定位** | 🍜 美食（板前 Omakase 料理） |
| **營業時間與預算** | 12:00–14:00、18:00–22:00｜午餐 ¥15,000 起、晚餐 ¥25,000 起 |
| **地址** | 東京都中央区日本橋室町 1-13-7 |

## 2. 特色與推薦重點
- **季節性 Omakase 套餐**：結合開胃前菜、白身魚刺身、時令握壽司與炙燒壽司，節奏流暢且食材豐富。

## 3. 排隊與順遊動線攻略
- **東京站與日本橋商圈**：餐廳距離 [東京車站](tokyo-station-souvenirs.md) 步行可達，適合安排在購物行程中的紀念日或質感午晚餐。
