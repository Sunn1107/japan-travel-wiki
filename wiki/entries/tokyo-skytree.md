# 東京晴空塔 (Tokyo Skytree)

高達 634 公尺的東京晴空塔是世界第二高建築與東京代表性新地標，天氣晴朗時登塔不僅能 360 度俯瞰東京全景，甚至能遠眺富士山。

## 1. 基本情報表

| 項目 | 詳細資訊 |
| :--- | :--- |
| **所屬城市與商圈** | 東京 Tokyo（墨田區・押上） |
| **分類定位** | 🏯 景點（高空展望台） / 🎁 商場伴手禮 |
| **營業時間** | 10:00 – 21:00 |
| **地址** | 東京都墨田区押上 1-1-2 |

## 2. 特色與推薦重點
- **雙層高空展望台**：分為 350 公尺的「天望甲板」與 450 公尺的「天望回廊」，樓層越高視野越開闊。
- **東京 Solamachi 購物中心**：塔下商場進駐超過 300 間店鋪與餐廳，可一站式採購晴空塔限定伴手禮與人氣雜貨。

## 3. 排隊與順遊動線攻略
- **步行串聯淺草**：晴空塔距離淺草僅一站地鐵或步行約 15～20 分鐘，推薦上午逛完 [淺草寺與雷門](sensoji-kaminarimon.md) 後，下午安排登塔與逛街。
